3

Print / Input

Display text and ask the user a question

4

Comments & Indentation

Notice the four spaces inside the if block 
# comment
if True:
    print("inside - 4 spaces")
print("outside")
5

If / While / For

Make decisions and repeat actions 
yearofexp = 4
if yearofexp > 3:
    bonus = 10000
else:
    bonus = 5000
print(bonus)
for i in range(3):
    print("Hi", i)
What should you notice?
The if and else blocks choose a bonus based on the condition. The for loop runs three times, with i taking the values 0, 1 and 2.
6

Advanced Data Types

Lists, tuples, sets and dictionaries 
nums = [1,2,3]
t = (1,2,3)
s = {1,2,2,3}
p = {1: 6, 2: 6, 3: 6, 4: 6, 5: 6, 6: 6}
for i, j in p.items():
    print("ROW:", i, "-\t", j * '1 ')
Explore the data structures
  • nums is a list.
  • t is a tuple.
  • s is a set, so repeated values are stored only once.
  • p is a dictionary mapping each key to the value 6.

The loop visits each key-value pair in p and prints a row made from repeated 1 text.

⭐ Optional project extension — Pop-it Game & Tower of Hanoi

Pop-it Game starter

def letusplay():
    p = {1: 6, 2: 6, 3: 6, 4: 6, 5: 6, 6: 6}
    for i, j in p.items():
        print("ROW:", i, "-\t", j * '1 ')
user_response = input('Do you want to play?\n')
if user_response.lower() in ["yes","y"]:
    letusplay()

Tower of Hanoi

def hanoi(n, source, target, aux):
    if n == 1:
        print(f"Move disk 1 from {source} to {target}")
        return
    hanoi(n-1, source, aux, target)
    print(f"Move disk {n} from {source} to {target}")
    hanoi(n-1, aux, target, source)
hanoi(3, 'A', 'C', 'B')
